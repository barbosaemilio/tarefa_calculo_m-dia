## 📌 Sobre o Projeto

Este repositório reúne exercícios práticos desenvolvidos para consolidar os fundamentos da linguagem **Java**. O foco principal do projeto foi transicionar dos conceitos básicos de **variáveis, classes e métodos** para a aplicação hands-on de **operadores** e entrada de dados interativa via terminal.

O projeto culminou no desenvolvimento de uma **Calculadora de Média Escolar**, onde foi possível aplicar a teoria em um fluxo de código funcional.

---

## 🎯 Conceitos Estudados & Praticados

Durante o desenvolvimento deste projeto, foram explorados os seguintes tópicos da linguagem:

### 1. 🏗️ Estrutura e Métodos
* Criação de classes (`public class`) e métodos de entrada (`public static void main`).
* Organização do código em métodos auxiliares (`private static void`).
* Manipulação de variáveis primitivas (`int`, `double`, `boolean`).

### 2. 🧮 Operadores Aritméticos
* Aplicação das operações fundamentais: adição (`+`), subtração (`-`), multiplicação (`*`) e divisão (`/`).
* Controle de precedência matemática utilizando parênteses `()`.

### 3. ➕➖ Incremento e Decremento
* Manipulação e alteração do valor de variáveis utilizando os operadores `++` e `--`.

### 4. 🔍 Operadores Relacionais
* Comparações lógicas e verificação de igualdade/diferença (`==`, `>`, `<`, etc.), retornando valores booleanos (`true` / `false`).

### 5. 📝 Operadores de Atribuição
* Atribuição simples (`=`) e operações compostas de atribuição (`+=`).

### 6. ⌨️ Entrada de Dados (`Scanner`)
* Utilização da classe `java.util.Scanner` para captura de dados digitados via teclado diretamente no terminal.

---

## 💻 Como Funciona a Calculadora de Média

A aplicação solicita que o usuário informe 4 notas no terminal. Em seguida, o sistema realiza a soma e calcula a média aritmética simples, exibindo o resultado formatado na tela.

### Exemplo de Execução:

```text
***CALCULADORA DE MÉDIA***
Digite a primeira nota: 7.5
Digite a segunda nota: 8.0
Digite a terceira nota: 6.5
Digite a quarta nota: 9.0

Sua média foi: 7.75
